# Lampa Winter Royale

Профессиональная бесплатная новогодняя тема для **Lampa 3.4.4**: королевский красный, золото, мягкий снег и праздничные SVG-объекты без помех для ТВ-навигации.

## Возможности

- Красно-золотая палитра по умолчанию и дополнительная изумрудно-золотая палитра
- Падающий снег позади интерфейса
- Тонкая снежная кромка на постерах, не закрывающая изображение и рейтинг
- Верхняя гирлянда с колокольчиками, подарком и леденцами
- Золотая ёлка у края экрана
- Редкое появление саней Деда Мороза
- Красно-золотые настройки, диалоги, меню, кнопки и фокус карточек
- Отдельный переключатель каждого декоративного элемента
- Режимы производительности: Экономный, Сбалансированный (TV), Максимальный
- Поддержка `prefers-reduced-motion`
- Все декорации имеют `pointer-events: none` и не перехватывают пульт или мышь

## Установка

В Lampa откройте **Настройки → Плагины → Добавить плагин** и укажите:

```text
https://cdn.jsdelivr.net/gh/DoubleGGameRR/Lampa-Winter-Royale@main/winter-royale.js
```

Полностью перезапустите Lampa. Параметры темы появятся в **Настройки → Winter Royale**.

## Совместимость

- Целевая версия: Lampa 3.4.4
- Браузеры и Smart TV, включая Samsung Tizen
- ES5-совместимый JavaScript без модулей и сторонних библиотек
- Внешних скриптов, аналитики, рекламы и трекеров нет

SVG-файлы загружаются из того же GitHub/CDN-каталога, что и плагин. Для стабильной установки используйте jsDelivr-ссылку выше, а не GitHub Raw.

## Проверки

```text
npm run check
npm test
```

Smoke-тест проверяет регистрацию настроек, внедрение стилей и сцены, основной переключатель, режим TV по умолчанию, разрешение путей ассетов и повторную загрузку плагина.

Реальный телевизор всё равно необходим для окончательной визуальной проверки: отдельные форки Lampa могут иметь изменённые CSS-селекторы.
